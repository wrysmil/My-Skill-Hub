# 💰 05-business — 看懂生意，技术之外的必修课

> **要回答的问题：这东西怎么变成钱？数字算得平吗？**

## 什么时候进入

- 当产品已经被验证有用，需要回答"那它怎么赚钱"的时候。
- 当你要用技术背景快速判断一个陌生行业值不值得做、该怎么在几天内摸熟它的时候。
- 当你要算单位经济 —— 获客成本、生命周期价值、毛利 —— 却不知道从哪几个数开始的时候。
- 当你要对 A 股上市公司做基本面分析，需要取数与量化评估的时候。
- 当有人告诉你"这个市场很大"，但你说不清自己能从里面拿到多少的时候。

## 什么时候不该进入

- 产品价值还没被验证 —— 没人用的东西谈不上商业模式，先回 `04-verify`。
- 你只是想把商业模式写成一份漂亮的计划书去融资，而不是真的在判断它成不成立。

## 产出物

- 一页商业模式画布：客户是谁、提供什么价值、通过什么渠道、靠什么收钱。
- 一份算得出数的单位经济表：CAC、LTV、毛利、回本周期，每个数字都有来源。
- 3 个决定这门生意成败的关键数字，以及它们的当前值和健康区间。
- 需要时，一份目标公司或行业的量化评估结论。

## 常见反模式

**「先把产品做好，商业模式以后再说」** → 商业模式决定了产品该长什么样，"以后再说"往往意味着推倒重来。

**「市场规模大就是好生意」** → 大市场里你只占一个极小的切面，而且大概率挤满了比你更早、资源更多的对手。

**「投资人会告诉我们怎么赚钱」** → 投资人的职责是判断回报，不是替你想清楚商业模式；说不出怎么赚钱的团队通常拿不到钱。

**「收入减成本就是利润」** → 漏掉获客成本、履约成本、退款与坏账之后，账面盈利的生意可能每单都在亏。

## 下一步

当单位经济算得平、关键数字在健康区间，说明这门生意具备继续投入的基础 —— 通常会回到 `02-design`，用更完整的方案去放大已验证的模式。如果算完发现模式不成立（比如获客成本永远高于 LTV），应该回退到 `01-discover` 重新选择问题或人群，而不是靠加大投入硬撑。
