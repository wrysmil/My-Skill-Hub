# 基本面分析框架

## 四维度分析体系

### 一、盈利能力（权重：ROE 40% + 毛利率 30% + 净利率 30%）

#### 核心指标
- **毛利率** = (收入 - 直接成本) / 收入 × 100% — 产品定价能力与成本控制
- **净利率** = 净利润 / 收入 × 100% — 整体盈利效率
- **ROE** = 净利润 / 净资产 × 100% — 股东资本回报效率（巴菲特最看重）
- **ROA** = 净利润 / 平均总资产 × 100% — 资产利用效率

#### 杜邦拆解
ROE = 销售利润率 × 总资产周转率 × 权益乘数
- 高毛利型：产品溢价能力强
- 高周转型：效率驱动
- 高杠杆型：负债风险较高

#### 评分标准
| 指标 | 绿灯(80-100) | 黄灯(60-79) | 红灯(0-59) |
|------|-------------|-------------|-----------|
| ROE | ≥15% | 8-15% | <8% 或为负 |
| 毛利率 | 高于行业均值 | 接近行业均值 | 远低于行业均值 |
| 净利率 | >15% | 5-15% | <5% 或为负 |

#### 常见误区
- 光看净利润，忽略非经常性损益（政府补贴、资产出售）
- 只看一年数据，需连续3-5年趋势

### 二、偿债能力（权重：资产负债率 40% + 流动比率 30% + 现金流动负债比 30%）

#### 核心指标
- **流动比率** = 流动资产 / 流动负债 — ≥2.0 为健康
- **速动比率** = (流动资产 - 存货) / 流动负债 — ≥1.0 为健康
- **资产负债率** = 总负债 / 总资产 — 制造业不宜超60%
- **现金流动负债比** = 经营现金流 / 流动负债 — 正数为健康

#### 评分标准
| 指标 | 绿灯(80-100) | 黄灯(60-79) | 红灯(0-59) |
|------|-------------|-------------|-----------|
| 资产负债率 | <50% | 50-70% | >70% |
| 流动比率 | ≥2.0 | 1.0-2.0 | <1.0 |
| 现金流动负债比 | 持续为正 | 波动 | 持续为负 |

#### 关键预警
- 流动比率 < 1：高危信号
- 存贷双高：账面大量现金却背负高额贷款（康美药业案例）

### 三、营运能力（权重：经营现金流 40% + 应收周转率 30% + 自由现金流 30%）

#### 核心指标
- **应收账款周转率** = 销售收入 / 应收账款均值 — 回款速度
- **存货周转率** = 销售成本 / 平均存货 — 库存管理效率
- **总资产周转率** = 营业收入 / 平均总资产 — 资产利用效率
- **自由现金流(FCF)** = 经营活动现金流 − 资本支出 — 真实可支配现金

#### 评分标准
| 指标 | 绿灯(80-100) | 黄灯(60-79) | 红灯(0-59) |
|------|-------------|-------------|-----------|
| 经营现金流 | 持续为正 | 波动 | 持续为负 |
| 应收周转率 | 高于行业均值 | 接近行业均值 | 远低于行业均值 |
| 自由现金流 | 持续为正 | 波动 | 持续为负 |

#### 关键预警
- 利润年年增长但经营现金流持续为负 → 利润可能是账面游戏

### 四、发展能力（权重：营收增长率 40% + 净利润增长率 40% + 研发投入占比 20%）

#### 核心指标
- **营收增长率** — 业务扩张速度
- **净利润增长率** — 盈利增长趋势
- **研发投入占比** = 研发费用 / 营业收入 — 创新能力

#### 评分标准
| 指标 | 绿灯(80-100) | 黄灯(60-79) | 红灯(0-59) |
|------|-------------|-------------|-----------|
| 营收增长率 | >15% | 0-15% | <0% |
| 净利润增长率 | >15% | 0-15% | <0% |
| 研发投入占比 | 高于行业均值 | 接近行业均值 | 远低于行业均值 |

## 非财务分析维度

### 护城河分析
- 品牌壁垒（如茅台毛利率≥90%）
- 技术壁垒（持续高研发投入）
- 规模效应
- 网络效应
- 转换成本

### 管理层诚信
- 大股东违规减持记录
- 资金占用问题
- 司法记录（天眼查）
- 高管频繁变动

### 审计意见
- 标准无保留意见：正常
- 保留意见 / 无法表示意见 / 否定意见：立即警醒

## 综合评分

四维度加权平均 → 总分(0-100)
- 80-100：🟢 基本面稳健
- 60-79：🟡 需要关注
- 0-59：🔴 存在风险
