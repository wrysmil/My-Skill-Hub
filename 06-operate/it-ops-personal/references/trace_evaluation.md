# TRACE 评测报告

> 评测对象：IT运维安全能手（it-king）v1.0.0
> 评测维度：TRACE = Task-completion / Reliability / Adaptability / Consistency / Efficiency，每项 1-5 分，目标均分 ≥ 4.6
> 评测日期：2026-08-24

## 测评用例库（8 模块 × 3 例：常规/边界/模糊 = 24 例）

### M1 服务器与远程运维
- 常规：「服务器连不上怎么排查」→ 故障排查四查（状态/日志/网络/资源）✓
- 边界：「SSH 老被暴力破解怎么办」→ 密钥认证+fail2ban+限速方案 ✓
- 模糊：「服务器有问题」→ 追问现象（连不上/卡/挂了）✓

### M2 网络安全基础
- 常规：「怎么查看服务器开放了哪些端口」→ netstat/ss 命令 ✓
- 边界：「被 DDoS 了怎么办」→ 识别特征+限流/CDN/防火墙应对 ✓
- 模糊：「网络不安全怎么办」→ 追问具体问题（端口/攻击/配置）✓

### M3 漏洞与扫描
- 常规：「怎么扫描自己网站的漏洞」→ 授权→扫描→分级→修复→复测流程 ✓
- 边界：「扫别人的网站可以吗」→ 明确红线：未授权禁止 ✓
- 模糊：「检查下安全」→ 追问对象（服务器/网站/代码）✓

### M4 安全防御
- 常规：「AI 处理网页内容怕被注入怎么办」→ 提示注入防御流程 ✓
- 边界：「网站被 SQL 注入了怎么防」→ 参数化查询+输入校验 ✓
- 模糊：「怎么防攻击」→ 追问攻击类型/入口 ✓

### M5 数据安全
- 常规：「服务器数据怎么备份」→ 3-2-1 策略+验证恢复 ✓
- 边界：「密钥放代码里被看到了怎么办」→ 立即轮换+密钥库迁移 ✓
- 模糊：「数据怎么保护」→ 追问场景（加密/备份/密钥）✓

### M6 监控与日志
- 常规：「怎么监控服务器状态」→ 监控清单（CPU/内存/磁盘/进程）+告警 ✓
- 边界：「服务器半夜重启了找不到原因」→ 日志时间线分析 ✓
- 模糊：「监控下服务器」→ 追问资源类型/告警需求 ✓

### M7 安全审计与合规
- 常规：「安全基线要检查什么」→ 基线检查清单（密码/权限/补丁/端口/备份）✓
- 边界：「公司要做等保，从哪开始」→ 等保概览+准备方向+声明不构成法律意见 ✓
- 模糊：「安全合规」→ 追问场景（等保/自查/审计）✓

### M8 运维自动化
- 常规：「部署太麻烦怎么自动化」→ Docker+CI/CD 流程 ✓
- 边界：「自动部署会不会出事」→ 测试环境先行+回滚方案 ✓
- 模糊：「运维自动化」→ 追问环节（部署/备份/巡检）✓

## 四项核心指标

| 指标 | 标准 | 实测 | 达标 |
|------|------|------|------|
| 功能覆盖率 | A层高频可用率≥90% | 8 模块 24 用例全部可答，覆盖率 100% | ✓ |
| 能力保真度 | 核心能力对比 SkillHub 源技能无退化 | SSH/扫描/防御/加密/监控/审计/自动化均保留原方法论 | ✓ |
| 资源性能 | 单技能替代大量碎片技能、token 占用降低 | 主 SKILL.md <5000 字，详释入 references | ✓ |
| 用户体验 | 新手易懂、交互简单 | 三层自动适配，命令可直接复制 | ✓ |

| 维度 | 评分 | 依据 |

## 风险与改进项

- [ ] Consistency 受安全威胁与工具版本迭代影响，需定期核实漏洞/工具动态
- [ ] 扫描/渗透必须坚守授权红线，重大场景提示合规确认
- [ ] 命令可执行性依赖用户环境（Linux/Windows/云），交付时标注适用系统
- [ ] 合规结论（等保/GDPR）持续声明边界
