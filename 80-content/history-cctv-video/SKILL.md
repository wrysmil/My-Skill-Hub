# 历史名场面监控短剧

将一个可识别的历史或文学场面，重新写成“被固定监控机位偶然记录”的短剧。流程为 **选题 → 短剧本 → 主体资产 → 分镜拆分**。剧本决定资产，资产约束分镜；不要跳过剧本直接罗列镜头。

## 创作边界

- 参考片只提炼镜头语言、叙事形式与可生成的动作组织方式。不要把其中的角色定妆、动物、道具、场景布局、动作顺序或三个十秒片段设为系列模板。
- 系列可复用监控形式，不默认跨历史时期复用同一批角色。武松题材需要老虎是情节需要，不等于必须沿用某参考片的虎纹、服装或打斗设计。
- 区分史事有据、演义细节、文学虚构、民间传说和本集原创。一个选题可以混合多个层级；不要把武松打虎当作已证史实，也不要把三顾茅庐的所有流行细节都当作正史。
- 普通成片不可能还原真实历史影像。监控机位、界面、原创对白与压缩时间是创作装置；成片建议标注“AI演绎”或相应改编说明。

## 判断从哪里开始

先读本轮要求及已有项目文件，只询问真正影响结果的缺项。

| 当前输入 | 本轮动作 |
|---|---|
| 仅要选题，尚未决定 | 给候选和推荐理由，在此结束；不提前写完整剧本、资产、分镜 |
| 指定一个场面并要求制作 | 视为已选题，核对必要背景后直接往下做 |
| 明确让你代选并直接做 | 推荐并代选一个，简述理由，连续完成后续流程 |
| 已有剧本或资产，只改分镜 | 复用已有版本与ID，只处理指定部分；先找项目资料，缺失时询问必要内容 |
| 要创建这个技能本身 | 交付可复用技能，不擅自把举例当作本集已选题 |

缺省采用中文、约30秒、16:9、写实固定高机位、少量对白、Seedance视频提示词。它们都是可覆盖的起点；不是所有经典场面都要打斗，也不是都要冷灰树林。按场所选择门厅、院落、走廊、街口、营门等合理视点。用户指定画幅、时长、风格或模型时以其为准。

## 第一阶段 选题

读取 [选题与短剧本](references/topic-and-script.md)。

通常提供5个候选，比较：观众识别线索、截取哪一次具体行动、适合的固定机位、内容依据层级、生成难点及可借鉴的情绪。推荐一到两个，解释取舍；没有平台数据就不宣称爆款或给伪精确潜力分。

用户只给大事件时，收敛到一个可见瞬间。例如多次拜访可选最后一次候见，战役可选营门递令；不要默认把整段人生或战争压成30秒。

## 第二阶段 短剧本

按上述参考完成 EpisodeBrief 与 Script，再进入资产：

- 确定一句话故事、观众识别点、冲突、一个变化及结局。
- 列出来源与改编边界；事实核验按内容需要检索可靠资料或原典。看过全文才写“已核对”，不把搜索摘要当详细考证。
- 写3–6个可见节拍，每段包括行动、对白或声音、时长、人物状态变化。数量随事件调整。
- 用监控内可见的行为讲清因果；不能只写内心独白，不能靠标题补一个画面里未发生的结局。
- 时长要装得下动作和对白；默认预留停顿。先删枝节，必要时缩短台词，而非靠极快语速塞满。

## 第三阶段 主体资产

读取 [资产与分镜契约](references/production-contracts.md) 的资产部分。根据已完成剧本提取角色、动物、场景、道具与必要状态变体；非每集都必须含动物。

每项建立ID、版本、外观或空间锚点、用途、参考图提示词及状态。场景资产包括机位与进出方向；角色资产包括服装与年龄感。需要画外音时，列出声音来源，不把新人物藏在配音里跳过清单。

**区分设计与生成：**

- 请求“方案、提示词、制作包”时，资产以 `text_designed` 交付。
- 用户要求“出图、生成角色参考图”等实际图片时，在已有授权与工具能力内调用图像工具；需要方舟/即梦工具时读取对应生成技能。不要把只写提示词当作出图完成。
- 每张图生成后查看并核对资产锚点，保存实际路径和来源。通过后记为 `visual_checked`；仅在用户已定稿或授权代定稿且完成检查时记为 `visual_locked`。
- 无工具、凭证或生成失败时，保留已完成文字资产，明确缺口；不要伪称角色参考图已经存在或已经锁定。
- 概念参考图、角色联系表和可直接投喂的独立首帧用途不同。不要把一张多宫格宣称为已经生成的多个独立文件。

通常资产图未生成也可交付注明“图像待生成”的文字分镜，未定稿外观不得宣称跨镜已验证一致。但用户明确要求先实际出图、再拆镜时，应遵守该顺序；出图受阻只交付可完成的资产准备与具体缺口，不擅自跳到分镜。

## 第四阶段 分镜拆分

读取同一参考的分镜部分。输入必须包含 EpisodeBrief、短剧本和 AssetPack。

- 每镜一个主要动作或一个可读的情绪变化。镜头持续时间随动作决定；不从参考片抄固定镜数或切点。
- 每镜交付独立静态首帧提示词、动态视频提示词、资产引用、起止状态、对白音效及衔接。不要用一句“同上”替代可复制提示词。
- 静态提示词负责人物、构图、姿态、场景、光色与镜头；动态词负责谁先做什么、如何结束、机位如何保持。
- 同机位连续段复用构图和合格尾帧；切机位时明确新的空间关系。后期角标相同不能掩盖错误轴线或场景漂移。
- 动作复杂时先减少接触点与同时运动主体，再拆分起势、遮挡和结果；不以更多形容词代替可执行动作。
- 监控形式允许少量合理机位切换；不默认环绕、航拍、景深特写或电影推拉。用户明确更换风格时相应调整。

## 模型和工具衔接

视频提示词默认中文自然语言，不混入其他平台的参数后缀。用户没指定Seedance版本时，先交付不依赖专属参数的镜头描述。正式调用前核对当前入口的官方规格、素材规则和所需参数；不固定所谓最新版本、时长上限或保证参考图效果。

本技能负责选题到可执行分镜。实际出图按第三阶段执行；实际生视频、上传到第三方或发布仅在用户请求相应动作时衔接对应工具。用户要求继续执行已授权环节时，不重复申请许可。实际生成状态以工具返回与查看结果为准。

## 保存与交付

尊重现有项目规范；默认工作区 `video-projects/<episode-id>/`：

1. `episode-brief.md`：选题、依据、来源与改编边界、时长画幅。
2. `script.md`：短剧本、节拍、对白和可见结局。
3. `assets.md`：资产ID、外观和机位锚点、独立生图提示词、真实生成状态。
4. `storyboard.md`：逐镜表及可单独复制的首帧、生视频提示词。

仅选题或局部请求只交付相应部分，不为凑文件擅自写后续。文件较短时可合并为一份清楚分段的制作包。持续制作时先读已有文件和版本，保留用户已定的选择。

## 完成前检查

- 选题和来源层级准确，原创动作、台词未冒充史料；标题承诺在剧本画面中兑现。
- 短剧本先于资产和分镜成立；所有出场人物、动物、声音来源、关键道具已登记。
- 分镜资产ID及状态变体存在，起始状态与上镜结束状态兼容。
- 时间轴连续无重叠，总时长与用户要求一致；动作与对白有完成空间。
- 每镜有独立生图、生视频提示词，构图适合指定画幅，监控形式自洽。
- 文本资产、已出图、已验图、已定稿、已生成视频分别如实标记；不保证热度或生成相似度。
