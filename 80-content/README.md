# 🎬 80-content — 内容创作，与 Builder 主线并行的另一条轨道

> **要回答的问题：怎么把一个想法变成能让人看完、并且愿意追更的内容？**

## 什么时候进入

- 要做一个 **AI 短视频系列**（历史短剧、科普剧情、固定 IP），需要从选题一路做到可直接执行的分镜。
- 已经选定了题材，要给角色、场景、道具建立**带 ID 与版本**的资产，保证跨集不漂移。
- 要把一个历史或文学场面，改写成"被固定监控机位偶然拍到"的短剧。
- 要把一个与观众有关的科学问题，拍成角色正在经历的科幻故事。

## 什么时候不该进入

- 你要做的是**产品**（软件、服务、工具），不是内容 —— 先回 `01-discover`。
- 你只想让 Agent 直接出片，不打算先把选题、剧本、资产定下来。这一阶段交付的是**文本制作包**，实际出图 / 生视频是后续另行请求的动作。
- 你还没决定选题，却想直接要分镜 —— 未选定就停在选题环节，这是刻意的。
- 你要把已有视频逐镜反推成提示词，或者只是问历史问题 —— 都不是这两个技能的适用范围。

## 产出物

一份可执行的制作包，通常拆成四份文件：

| 文件 | 内容 |
| --- | --- |
| `episode-brief.md` | 选题、观众与识别点、事实依据与改编边界、故事节拍、对白 |
| `assets.md` | AssetPack：角色 / 场景 / 关键道具 / 状态变体，各自的 ID、锚点与独立生图提示词 |
| `storyboard.md` | 逐镜表 + **每镜可单独复制**的首帧提示词与动态视频提示词 |
| `generation-plan.md` | 资产生成与镜头生成的先后顺序、配音字幕建议、自检结果 |

只做选题或只做局部时，按请求缩小交付，并标明覆盖范围与待补项 —— 不为了凑齐四份文件擅自往下写。

**资产状态必须如实标记。** 这两个技能共用一套状态词汇：

| 状态 | 含义 |
| --- | --- |
| `text_designed` | 只有设计与提示词，**还没有图片文件** |
| `visual_checked` | 图已生成，并逐项核对过资产锚点 |
| `visual_locked` | 用户已定稿（或授权代定稿）且完成检查，可跨镜复用 |

## 技能

| 技能 | 什么时候用它 |
| --- | --- |
| [`alien-science-video`](alien-science-video/) | 做固定双主角的 AI 科普剧情短视频：选题共创 + 证据台账 → 主体资产提取 → 分镜拆分 |
| [`history-cctv-video`](history-cctv-video/) | 把历史 / 文学经典场面改写成"被监控拍到"的短剧：选题 → 短剧本 → 主体资产 → 分镜拆分 |

两个技能都自带 `references/`（角色圣经、专家契约、选题与证据、研究依据等），正文只在需要时引用，不一次性灌进上下文。

## 常见反模式

**「让 AI 直接出片」** → 剧本决定资产，资产约束分镜。跳过剧本直接罗列镜头，得到的是一堆互不相干但各自好看的画面。

**「资产已经锁定了」（其实只写了提示词）** → 只写提示词不等于出图。没有实际图片文件就不能标记 `visual_locked`；把一张多宫格概念图宣称成"已经生成的多个独立首帧"是同一类错。

**「这是真实历史影像」** → 监控机位、界面、原创对白与压缩时间都是**创作装置**。成片应标注"AI 演绎"，并区分史事有据、演义细节、文学虚构、民间传说与本集原创 —— 不要把武松打虎当已证史实。

**「台词塞得下就行」** → 时长要装得下动作和停顿。内容超了先删枝节，必要时缩短台词，而不是靠极快语速塞满。

**「参考片这么拍，我也这么拍」** → 参考片只能提炼镜头语言与叙事形式。角色定妆、动物、道具、场景布局、动作顺序都不能变成系列模板（武松题材需要老虎，不等于要沿用某参考片的虎纹与打斗设计）。

**「自评分高就是爆款」** → 没有平台数据就不要宣称热度，也不要给伪精确的潜力分。区分"有传播潜力"和"已有传播数据"。

**「把缺证据的机制镜先拍了再说」** → 证据不足时可以交付生活开场、角色与普通场景，把缺证据的机制镜与答案**标为阻塞**并列出待核实结论，而不是虚构机制或来源。

## 下一步

制作包完成、且资产实际出图并核对通过后，再衔接生图 / 生视频工具。这一阶段负责选题到可执行分镜，实际生成、上传与发布都只在明确请求时才做。

这条轨道与 Builder 主线互不依赖。如果内容要**变现**，回 `05-business` 算单位经济；如果要验证**观众是否真的在看**（而不是你自己觉得好看），回 `04-verify`。
