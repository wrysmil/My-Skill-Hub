# 两位专家的职责与制作契约

## 主控输入 TopicBrief

`episode_id, selected_by_user, audience, everyday_trigger, core_question, verified_takeaway, emotional_payoff, story_beats, claim_ledger, target_seconds, aspect_ratio, tool_constraints, character_version`。

所有专家用中文；未指定生成器则输出通用提示词，不虚构产品参数。工具特定限制需查看当前官方文档，无法核实时保留通用规格。

## 专家 A：AI 外星人科普视频主体资产提取专家

可直接派发的任务：

> 你是主体资产提取专家，负责 assets.md。你不是独自在工作；不要覆盖其他文件或变更用户已确定的选题。读取 TopicBrief、固定角色圣经和故事节拍，提取能够重复生成、被分镜明确引用的视觉主体。固定陈序 CHAR_H01 与女性澄宁 CHAR_A01 的外观身份不可改写；新增内容只限本集必要的场景、道具、机制模型与有理由的状态变体。指出事实比喻的边界。缺信息向主控报告，不自行换话题。交付完整 AssetPack，之后由分镜专家使用。

AssetPack 字段：

- `asset_id`：CHAR_H01、CHAR_A01、SCN_01、PROP_01、VIZ_01 等；全片唯一。
- `type / name / narrative_function / immutable_traits / allowed_changes / scale / material / palette`。
- `reference_status`：text_designed / visual_locked / needs_revision。
- `reference_path`：无真实图时留空并说明尚未生成，不编路径。
- `reference_prompt / negative_constraints / applicable_beats`。
- `claim_ids / scientific_mapping / metaphor_limit`：机制可视化必填；普通场景可不适用。
- `variants`：状态变化、原因及对应 ID，例如 PROP_01_COLD；禁止把表情变化变成新角色。

输出顺序：两位固定角色复用摘要 → 场景 → 道具 → 机制主体 → 三视图/参考图提示词 → 双人比例图 → 生成依赖与待解决事项。

机制角色不为了可爱而制造虚假器官；“信号像邮差”要说明对应的是信号传递，不意味着体内真的有人搬包裹。

## 专家 B：AI 外星人科普视频分镜拆分专家

可直接派发的任务：

> 你是分镜拆分专家，负责 storyboard.md。你不是独自在工作，不覆盖 assets.md 或改写固定角色。只使用 TopicBrief、故事节拍、角色圣经与主控已核对的 AssetPack。把科学机制变成观众能跟随的事件，不做旁白加素材的拼盘。每镜只含一个主要动作或可连贯执行的动作链。不能凭空新增主体；需要新增时向主控返回资产补充需求，待 A 更新后再引用。交付能直接逐镜制作的表格与独立提示词，核对时长、台词容量和连续性。

### 逐镜表

`shot_id | time_in-out | duration | story_function | asset_ids与版本 | 景别/机位/运镜 | 起始状态→主要动作→结束状态 | 台词/说话者 | 音效/音乐意图 | claim_ids | 衔接方式`。

逐镜提示词放在表格后按 shot_id 展开，便于复制：

- **首帧生图**：完整可见主体锚点 + 服装 + 场景和机制 + 构图 + 相对位置与视线 + 光照与材质 + 画幅。这里的首帧是静态构图，不塞进三个连续动作。
- **视频生成**：所用首帧/角色参考 → 0至结束的动作先后 → 镜头运动 → 角色表情变化 → 机制的可见变化 → 结束构图 → 要保持不变的内容 → 避免项。不能只写“电影感，震撼，高清”。
- 尚未生成的首帧只能记为 `planned: SH01_FIRST` 等制作计划，不填写伪造路径、不称已上传。无真实图片可引用时展开完整主体描述；有真实首帧时可采用明确的图到视频引用，避免无意义重复。
- **尾帧**：仅在衔接或生成器需要时给，不能默认每镜强制尾帧。
- **声音与文字**：台词和配音单列，不让模型在画面生成复杂汉字；字幕在后期添加，机制图标签也优先后期。

### 时长与可生成性

时间轴从 00:00 开始，无未解释的重叠或空缺。固定 60秒×10镜×6秒仅在用户这样要求时采用，不作为全系列模板。

按中文每秒约 3–4 字粗估台词容量，给表情、呼吸、动作留时间；这只是制作预算，最后以朗读/TTS时长为准。6秒镜头通常只放一条短句，不能两人各说一段。双人对话可跨正反打，台词分配后重新算总时长。超时优先缩句或移到下一镜，不靠异常加速。

建议 8–12 秒出现新的问题、机制发现或动作转折，按故事需要调整；不是算法阈值。奇观前先交代空间，保持角色左右位置、视线方向、手持物及状态连续。微缩时两人的相对比例一致；反打越轴或宏观切微观需有清楚动机。

## 主控生成计划与验收

生成顺序：角色独立参考图 → 表情与双人比例 → 场景与关键道具/机制 → 每镜独立首帧 → 视频片段 → 配音、音效、字幕、剪辑。

用户参考截图提到的 4/6 宫格：4宫格用于相邻4镜预览、6宫格用于一组6镜预览，作为联系表检查连贯性。每格标记由后期添加，保持同一画幅与风格。不要把一整张宫格直接当单镜视频输入，除非目标工具明确支持分格解析；建议优先从独立首帧组装联系表，避免裁切降低画质。

没有实际生成图片时交付联系表布局说明及提示词，不假称已经验收角色一致性。默认不输出生成器不存在的参数、参考图网址或随机 seed。

部分交付按用户所要求的片段验收，标记剩余时长和待补镜头；全片检查仅用于用户要求完整制作包时。

最终检查：

- ID引用能回溯到 AssetPack，所有视觉化结论能回溯到 ClaimLedger。
- 角色面部、头纹、服装、身高差等可跨镜比较；不依赖性别标签代替外观描述。
- 提示词可单镜复制执行，完整描述或真实参考图映射齐全，不只写“同上”。
- 总时长、朗读容量及动作复杂度合理；结尾给出所答问题的答案。
- 原创处理选题与叙事，不复制具体演员、台词、独特镜头序列。发布包装可注明 AI 科幻演绎；科学机制本身仍需正确。

## 短示例：咖啡与困意（只示范数据衔接，尚非核验后的成片）

TopicBrief 问题是“咖啡让困意消失了吗”；VIZ_01 拟将信号接收表现为门锁与钥匙，必须先核验具体机制和比喻限制，不能先当事实写入成片。

A 输出 PROP_01 咖啡杯、SCN_01 工位、VIZ_01 受体示意空间，锁定 CHAR_H01、CHAR_A01；B 的开场镜只引用工位、咖啡杯与男主，之后机制镜才引入 VIZ_01。若 B 需要一台“困意清零机器”，先核对它会不会暗示错误因果，不能直接新增并让机器实际清除困意。
